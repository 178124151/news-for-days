## t-008: 合规、版权与自动质检

### 来源
> 摘录自 `raws/P001-原始需求.md`

「新闻平台」+ 用户确认「个人使用、不保留人工编辑」。

### 范围

包含：
- 版权策略：标题 + 80–200 字摘要 + 来源署名 + 原文链接；不转载全文、不镜像图片
- 来源审核：robots.txt、RSS 条款、是否允许聚合；付费墙只取标题
- 自动质检（替代人工编辑）：
  - JSON Schema 校验
  - 中文字符占比 ≥ 50%
  - 摘要长度 80–200 字
  - 禁用词：投资建议、必将、暴涨、独家、重磅等
  - 数字一致性：摘要中的数字应能在原文中找到；不通过则降级为抽取式摘要
  - 低置信度自动隐藏，不阻塞其他文章
- AI 标识：「AI 摘要 · 自动生成，可能有误」
- 免责声明：非投资建议、以原文为准
- 下架/更正：通过 GitHub Issue 提交，作者手动处理（非日常流程）
- 隐私：无账号、无评论、无 Cookie 追踪、不接入第三方分析
- 中国大陆合规：个人非商业、海外托管，暂不涉及 ICP；不提供新闻采编或许可证类服务
- 公开仓库意味着内容公开；不得把任何密钥写入仓库

不包含：
- 人工每日编辑流程（明确不做）
- 商业化、广告、会员
- 付费法律顾问

### 依赖
- 依赖：t-002, t-005
- 被依赖：无

### 关键约束
- 自动质检不通过时，宁可少发一条，也不发明显错误的内容
- 所有页面可追溯到来源 URL 与抓取时间
- 收到权利方通知后 24 小时内下架
- 站点页脚必须包含免责声明与联系邮箱
