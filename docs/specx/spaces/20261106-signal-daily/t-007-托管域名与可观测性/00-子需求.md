## t-007: 托管、访问与可观测性（零成本）

### 来源
> 摘录自 `raws/P001-原始需求.md`

「托管在 github 或 cloudflare」+ 用户确认「个人使用、中国大陆、成本尽可能低、最好无成本、可用 GitHub 免费域名」。

### 范围

包含：
- GitHub Pages 主托管：`https://178124151.github.io/news-for-days/`
- 仓库公开（GitHub Free 的 Pages 前提）
- 可选 Cloudflare Pages 免费镜像：`https://<project>.pages.dev`，同一构建产物，双部署
- 可观测性：
  - Actions 运行状态与失败通知
  - 每日 `data/health/YYYY-MM-DD.json`（源成功率、条数、AI 降级次数、构建耗时）
  - 部署后 curl 冒烟：首页、RSS、搜索索引
- 大陆访问说明：GitHub Pages 与 pages.dev 均可能被阻断；零成本无法保证稳定直连
- 主备切换：GitHub Pages ↔ Cloudflare Pages，同一份 `dist/`

不包含：
- 付费域名、ICP 备案、国内 CDN
- 付费分析服务
- 付费监控服务
- 每日邮件（本次不做，后续可选）

### 依赖
- 依赖：t-006
- 被依赖：无

### 关键约束
- 月度现金成本 $0；不引入任何需要绑卡的付费服务
- 自定义域名不是 MVP 范围
- 大陆访问质量必须在 README 中如实说明，不承诺「国内可直连」
- 本次不启用每日邮件；GitHub 失败通知由平台自带
