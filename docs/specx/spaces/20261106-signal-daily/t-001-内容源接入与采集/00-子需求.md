## t-001: 内容源接入与采集

### 来源
> 摘录自 `raws/P001-原始需求.md`

「每天定时获取内容……主要针对科技、金融、AI 领域的最新资讯」

### 范围

包含：
- 源清单配置（RSS / Atom 为主，公开 API 为辅，HTML 兜底）
- 抓取调度（并发、超时、重试、限流、User-Agent、ETag/Last-Modified）
- 原始条目落盘（保留 7 天，供审计与重跑）
- 采集健康度记录（每个源的成功率、耗时、条数）

不包含：
- 去重与聚类（t-002）
- AI 摘要（t-003）
- 页面展示（t-005）

### 依赖
- 依赖：无
- 被依赖：t-002, t-006

### 关键约束
- 遵守 robots.txt 与源站 ToS，默认 1 req/s/域名
- 单源失败不阻断整体流水线
- 采集结果必须可幂等重跑（同一时间窗不产生重复副作用）

### 类型
- [x] 抽象层（数据接入 / 领域规则）
- [ ] 实现层（页面 / 交互 / UI 组件）
