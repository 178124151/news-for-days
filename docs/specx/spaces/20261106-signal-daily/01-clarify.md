# Signal Daily — 需求澄清

**所属原始需求：** 科技 / 金融 / AI 每日资讯静态站
**空间目录：** 20261106-signal-daily

---

## 需求概述

做一个**仅供作者本人使用**的科技、金融、AI 每日资讯站：GitHub Actions 每天定时从公开 RSS/API 采集内容，经规范化、去重、聚类、免费 AI 中文摘要后，生成静态页面并自动发布到 GitHub Pages（`https://178124151.github.io/news-for-days/`）。不购买域名、不使用付费 API、不做人工编辑，月度现金成本目标为 **$0**。

## 用户场景

- 场景 1：早间 5–10 分钟——打开站点看今日 20–30 条精选，点进感兴趣的原文。
- 场景 2：按主题回看——进入 AI / 科技 / 金融分类，或搜索某个公司/事件。
- 场景 3：补课——查看历史日报存档。
- 场景 4（可选兜底）：站点在大陆打不开时，用代理或本地构建；每日邮件本次不做。

## 功能要点

- 20–30 个公开源，RSS 为主，API 为辅
- 规范化、URL/标题去重、同事件聚类
- 免费 AI：中文摘要、3 条要点、分类、标签、重要性评分
- 每日日报 + 分类流 + 详情页 + 站内搜索 + RSS
- GitHub Actions 每日定时构建，自动部署 GitHub Pages
- 全自动质检，无人工编辑
- 只展示标题、短摘要、来源与原文链接

## 边界情况

- 源站改版、RSS 404、空内容、重复内容
- 同一事件多家报道
- 免费 AI 限流、超时、返回非法 JSON、模型下线
- GitHub Actions 定时漂移或失败
- GitHub Pages 在中国大陆访问不稳定
- AI 摘要事实错误（无人工兜底）
- 版权投诉
