## t-005: 静态站点与信息架构（GitHub Pages）

### 来源
> 摘录自 `raws/P001-原始需求.md`

「托管在 github 或 cloudflare 的新闻平台……静态网页」+ 用户确认使用 GitHub 免费域名。

### 范围

包含：
- 页面：首页（今日头条 + 分类速览 + 最新流）、分类页、文章详情、日报存档、标签页、来源页、关于/免责声明、404
- 站内搜索（Pagefind 静态索引）
- RSS / Atom、sitemap、robots.txt、JSON-LD
- 自动生成 OG 分享图（不热链源站图片）
- 响应式、暗色模式、阅读时长、来源与发布时间
- GitHub Pages 子路径适配：`base: '/news-for-days'`，所有内部链接使用 `import.meta.env.BASE_URL`
- 空状态、构建失败占位、内容下架占位

不包含：
- 数据采集与加工（t-001–004）
- 部署流水线（t-006）
- 域名与监控（t-007）

### 依赖
- 依赖：t-003, t-004
- 被依赖：t-007, t-008

### 关键约束
- 零客户端运行时依赖（搜索除外），首屏为静态 HTML
- 项目站点 URL：`https://178124151.github.io/news-for-days/`
- 用户站点 URL：`https://178124151.github.io/`（仓库名必须为 `178124151.github.io`）
- LCP < 2.5s（4G），CLS < 0.1，Lighthouse Performance ≥ 90
- 所有详情页必须带来源署名、原文链接、AI 摘要标识
