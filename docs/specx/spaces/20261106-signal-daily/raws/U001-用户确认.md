# U001 — 用户确认（2026-11-06）

> 来源：用户在企划书 v1.0 后的补充说明
> 状态：只读，不修改

---

## 原话

> 首先产品为我个人使用，用户在中国大陆。
> 具体产品名和域名无所谓，可以使用 github 的免费域名，只要能够将成本尽可能压倒最低即可，最好无成本。
> 不保留人工编辑，使用免费的 AI 摘要或者机翻，只要能有一段中文摘要即可。

## 决策提取

| # | 决策 | 对方案的影响 |
|---|------|-------------|
| 1 | 个人使用 | 去掉增长、商业化、多用户、账号体系；指标改为个人阅读体验 |
| 2 | 用户在中国大陆 | 托管需评估大陆访问；零成本无法保证稳定直连；增加免费兜底 |
| 3 | 名称/域名无所谓 | 使用 `https://<username>.github.io/<repo>/`，不购买域名 |
| 4 | 成本尽可能低，最好无成本 | 全链路 $0；只使用免费额度；不绑卡 |
| 5 | 不保留人工编辑 | 全自动发布 + 自动质检；接受偶发错误 |
| 6 | 免费 AI 摘要或机翻 | 使用 Cloudflare Workers AI 免费额度 + OpenRouter 免费模型；GitHub Models 已退役 |
| 7 | 只要有一段中文摘要 | 摘要 80–200 字即可；不追求新闻级质量 |

## 新增约束

- GitHub Free 的 Pages 只支持公开仓库 → 仓库必须 public；
- 公开仓库意味着内容公开，不得提交任何密钥；
- 免费 AI 额度会变（GitHub Models 已于 2026-07-30 退役）→ 必须有 Provider 降级链；
- 大陆访问不稳定 → 至少准备一个免费兜底（镜像 / 邮件 / 本地构建）。
