## t-004: 内容存储与构建数据契约

### 来源
> 摘录自 `raws/P001-原始需求.md`

「托管在静态网页上」——静态站点的数据必须可版本化、可回滚、构建时可校验。

### 范围

包含：
- 仓库即数据库：`content/articles/*.json`、`content/digests/*.json`、`content/sources.json`
- TypeScript 类型 + Zod schema，构建前校验
- ID 规则（canonical URL hash）、日期分区、历史归档
- 原始数据与发布数据分层（`data/raw` 短期保留 / `content` 长期保留）
- 索引文件生成（按日期、分类、标签、来源）
- 回滚策略：内容与代码同仓，按 commit 回滚

不包含：
- 采集与加工逻辑（t-001/002/003）
- 页面组件（t-005）

### 依赖
- 依赖：t-002
- 被依赖：t-005, t-006

### 关键约束
- 单文件写入原子化，构建失败不得污染已发布内容
- 内容变更必须产生可读 diff，便于人工 review
- 数据量按 3 年、每天 40 条约 4.4 万条设计，构建时间可控

### 类型
- [x] 抽象层（数据契约 / 存储）
- [ ] 实现层（页面 / 交互 / UI 组件）
