## t-002: 内容规范化与去重

### 来源
> 摘录自 `raws/P001-原始需求.md`

「最新资讯」——同一事件常被多家媒体报道，必须避免重复刷屏。

### 范围

包含：
- 统一内容模型 `RawItem` → `Article` 的字段映射
- URL 规范化（去 utm/ref、统一协议与尾斜杠、解析 canonical）
- 去重：URL 精确去重 + 标题归一化 + SimHash 近似去重
- 同事件聚类：标题/实体/时间窗规则，V1.1 可接 embedding
- 时间窗与分类归属规则（AI / 科技 / 金融 / 政策）
- 质量过滤：空正文、广告、导航页、非目标领域

不包含：
- AI 摘要与评分（t-003）
- 存储格式与版本（t-004）

### 依赖
- 依赖：t-001
- 被依赖：t-003, t-004, t-008

### 关键约束
- 去重必须可解释：命中哪条规则、与哪条重复
- 聚类只影响展示排序，不删除原文记录
- 规则阈值配置化，便于按日调参

### 类型
- [x] 抽象层（数据模型 / 领域规则）
- [ ] 实现层（页面 / 交互 / UI 组件）
